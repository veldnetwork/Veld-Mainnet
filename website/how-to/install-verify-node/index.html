How-to / Veld Node

Install and verify Veld Node

Authenticate the first download, extract the client to a stable folder, and start the all-in-one node without weakening its release checks.

Open official downloadWindows · About 10 minutes
01Download02Verify03Extract04Start

01 / Download

Use the official release

Download the Windows client only from the Veld website. Avoid copies sent through chat, file-sharing services, advertisements, or third-party download pages.

https://veld.network/downloads/VeldClient-Windows-x64-3.1.1.zip
  • Supported system: Windows 10 or Windows 11, 64-bit.
  • Expected archive name: VeldClient-Windows-x64-3.1.1.zip.
  • Keep the download page open so you can compare its published SHA-256.

02 / Verify

Authenticate the first archive

The verifier inside a newly downloaded archive cannot be its own first-install trust anchor. Compare the ZIP digest with the value published on the official download page or an independently authenticated release announcement.

  1. Open Windows PowerShell

    Run the following command using the real path to the downloaded ZIP:

    Get-FileHash -Algorithm SHA256 "C:\Users\<your name>\Downloads\VeldClient-Windows-x64-3.1.1.zip"

  2. Compare all 64 hexadecimal characters

    The computed SHA-256 must exactly match the ZIP SHA256 shown at veld.network. A partial match is not sufficient.

  3. Stop on any mismatch

    Delete the untrusted archive and obtain the published value through an independent trusted channel before trying again.

Do not bypass a hash or signature failure. The signed launcher and updater reject missing signatures, altered files, unlisted files, downgrades, and same-version replacements with a different node hash.

03 / Extract

Put the client in a stable folder

  1. Extract the entire archive

    Right-click the ZIP, choose Extract All, and select a location you control. Do not run the app from inside the compressed ZIP viewer.

  2. Keep the folder together

    The executable, signed manifest, updater, supporting binaries, and veld-data directory belong together. Do not copy out only one executable.

  3. Avoid temporary or synchronized folders

    Use a stable local path. Moving or partially synchronizing the folder while the node runs can separate it from its data and identity files.

04 / Start

Launch Veld Node

  1. Open Start Veld Node.bat

    Double-click Start Veld Node.bat in the extracted folder. It verifies the signed package, checks for signed updates, and opens Veld Node on Clearnet. Complete a required signed update before mining.

  2. Handle the clearnet firewall request

    On first clearnet use, Windows may request approval for inbound P2P traffic on TCP 8333. The rule is limited to the signed node executable on Private or Domain networks. Declining leaves the node able to use outbound peers.

  3. Confirm the Overview page opens

    The app shows local node status, chain height, peers, and mining configuration. Its Wallet button opens https://wallet.veld.network/; Open Explorer opens https://explorer.veld.network/.

RPC and local app ports are not opened to the network. Node control and loopback services remain local-only. Public Wallet and Explorer buttons use HTTPS, not exposed RPC. TCP 8333 is the clearnet P2P port. The batch launcher explicitly selects Clearnet; open Veld Node.exe directly to retain a configured Tor-only preference.

Installation checklist

  • The ZIP came from veld.network.
  • The complete SHA-256 matched an authenticated published value.
  • The whole archive was extracted.
  • Start Veld Node.bat opened the client on Clearnet without a release-verification failure.
  • The Overview page reports the local node state.
