How-to / Portal

Pair Veld Node with the Portal

Connect one Veld Node installation to your Portal account with its temporary pairing code, then confirm the machine is online before leaving the computer.

Open Veld PortalAbout 5 minutes
01Account02Enable03Pair04Verify

01 / Account

Open the official Portal

Pair only through the exact HTTPS address below. You can use the node computer or another device you trust.

https://portal.veld.network/

  1. Confirm the address

    Check that the browser shows portal.veld.network over HTTPS before entering an account name, password, or pairing code.

  2. Create an account or log in

    New operators should enter an account name and password, then select Create account. Returning operators should select Log in.

    • Account names are 3 to 48 characters.
    • Passwords must be at least 12 characters.
    • Use a unique password and store it in a trusted password manager.

  3. Leave the Portal ready

    A new account displays Pair your first machine. If already paired, select + Add machine on Overview or Add machine in Settings. This works in the browser and installed Portal.

The Portal never needs a wallet keyfile or wallet passphrase. Do not enter either one into the Portal or send one to anyone claiming to help with pairing.

02 / Enable

Generate the code in Veld Node

  1. Open Settings

    On the node computer, open Veld Node and select Settings.

  2. Enable Remote access

    Turn on the Remote access toggle. The status first reads Connecting to the secure portal... while the protected device credential is prepared.

  3. Wait for the one-time code

    The status changes to Open the portal and enter the one-time code. A code in the format ABCD-EFGH appears beside it.

Code lifetime
15 minutes. Veld Node replaces an expired unclaimed code automatically while Remote access remains enabled.
Copy safely
Use Copy code when the Portal is open on the same computer. Otherwise type it directly on the trusted device.
Connection trouble
If Veld Node reports that the Portal is unavailable, leave it open; the app retries automatically.
Treat the code as temporary access authority. Anyone who submits it before expiration can attach this machine to their own Portal account.

03 / Pair

Claim the machine from the Portal

  1. Enter the complete code

    Type or paste all eight characters and the hyphen into the PAIR CODE field.

  2. Select Pair machine

    The Portal checks that the code exists, has not expired, and is still unclaimed. A successful claim opens the paired machine view.

  3. Stop if the machine is unexpected

    The device selector should show the computer you intended to pair. Do not continue issuing commands if the machine name or status is unfamiliar.

Pairing one machine does not expose or automatically pair any other Veld installation. Repeat this process from each additional machine.

04 / Verify

Confirm both ends of the connection

  • Veld Node reports that monitoring is connected. Open the Portal to enroll signed control; the first action asks you to trust this pairing locally, and each action requires approval on the computer.
  • The temporary code is no longer shown in Veld Node.
  • The Portal device selector shows the expected machine.
  • The Portal status reads Online and its height, peers, and other operational values begin updating.
  • Refresh once if the new machine takes a few seconds to appear.
Pairing authorizes remote operations, not just viewing. The Portal can request restricted operational commands. Each command requires approval on the node computer; pairing does not enable unattended control. Review the next guide before relying on it away from the machine.

Get a new code or change Portal accounts

On the node computer, select Settings → Remote access → New pair code and confirm the local reset warning. This removes the machine from its previous Portal account and revokes that pairing's command access. Keep Remote access enabled, sign in to the intended Portal account, and claim the fresh code. Switching Remote access off and on is not an account reset.

If you need to undo the pairing

Turn off Remote access locally to stop reports and remote commands immediately. To unlink the account as well, open Portal Settings and use Remove for that machine.

Troubleshooting

“Enter the complete pairing code”

Enter four characters, the hyphen, and the final four characters. Use the current code exactly as Veld Node displays it.

“Code is invalid or expired”

Return to Veld Node Settings and use the current code. An unclaimed code is replaced after 15 minutes. If the machine is still attached to an old account, use New pair code locally.

“Account name is unavailable”

Choose a different account name, or use Log in if the account is already yours.

“Too many pairing attempts”

Stop retrying, confirm the current code locally, and wait before trying once more. The Portal limits repeated claims to protect enrollment.

The Portal says Offline after pairing

Confirm that Remote access remains enabled, Veld Node is still running, and the local status reports monitoring connected or signed control enrolled. Ordinary node and mining operation continue if the Portal itself is temporarily unavailable.
