How-to / Wallet

Change your wallet passphrase

Replace the encryption on the current browser keystore, save a fresh keyfile, and verify the new backup before retiring old copies.

Open Veld WalletAbout 5 minutes
01Unlock 02Replace 03Save 04Verify

01 / Unlock

Prepare the current wallet

Before changing anything, confirm that you can unlock the wallet and that at least one known-good backup exists. The change affects the keystore stored in this browser.

  • Open only https://wallet.veld.network.
  • Unlock the address you intend to update.
  • Record the full Veld address for later comparison.
  • Keep the existing backup until the new one is verified.
This does not rewrite old files. Existing keyfile copies remain encrypted with the old passphrase until you securely remove or replace them. This does not change the on-chain address, update the node's miner.key, or revoke any already-exposed private key.

02 / Replace

Replace the browser encryption

  1. Open Wallet Settings

    With the wallet unlocked, select Settings. The window title should read Wallet Settings.

  2. Select Change passphrase

    Under Wallets & key, choose Change passphrase.

    Wallet Settings → Change passphrase

  3. Enter and confirm the new passphrase

    Use at least 16 characters. A password-manager value or Generate 128-bit multi-word passphrase is recommended.

  4. Select Replace encryption

    Wait for the confirmation that the passphrase changed. If replacement fails, the wallet reports that the existing keystore was not replaced.

Store the new passphrase separately. Do not place it in the same folder, drive, message, or account as the encrypted keyfile.

03 / Save

Download a freshly encrypted keyfile

Return to Wallet Settings and select Save file. This creates a new .veld-keys file using the replacement passphrase.

  1. Save the new file

    Keep its filename and download time clear so it cannot be confused with an older copy.

    veld-wallet-V1234567.veld-keys

  2. Copy it to the backup location

    Replace the intended encrypted backups, but do not erase the last known-good old copy yet.

04 / Verify

Test the new file before cleanup

  1. Use a separate browser profile

    Open the official wallet and select Import keystore file.

  2. Unlock with the new passphrase

    Select the newly saved file. The old passphrase should not be needed for this copy.

  3. Compare the complete address

    The imported address must match the address recorded before the change.

  4. Retire old copies deliberately

    Only after successful verification should old keyfiles and old-passphrase records be securely removed from the locations you control.

Do not delete the only working recovery copy. If the fresh file fails, return to the unlocked wallet, repeat Save file, and test again.
