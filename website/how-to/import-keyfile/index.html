How-to / Wallet

Import a keyfile into the Veld Wallet

Find the encrypted file, import it safely, and confirm that the wallet address is the one you expect.

Open Veld WalletAbout 5 minutes
01Find file 02Import 03Verify

01 / Find file

First, find your keyfile

A Veld keyfile is an encrypted file containing the signing identity for an address. Browser-wallet files normally end in .veld-keys.

If the wallet was created in a browser

Check the device’s Downloads folder or the browser’s Downloads history. The filename normally looks like:

veld-wallet-V1234567.veld-keys
Windows
C:\Users\<your name>\Downloads
macOS
/Users/<your name>/Downloads
Linux
/home/<your name>/Downloads
iPhone or iPad
Files → Browse → Downloads. Check iCloud Drive and On My iPhone/iPad.
Android
Open Files or My Files, then Downloads.

If the wallet is still unlocked, open Wallet Settings and select Save file to download a fresh encrypted copy.

If the identity was created by Veld Node

Open Veld Node, go to Settings → Local paths, and select Open data folder. Look for:

veld-data\veld-wallet-V1234567.veld-keys veld-data\miner.key

Use the .veld-keys file when present. The wallet can also read the encrypted miner.key identity file. After successful encrypted-identity sign-in, the current node creates the portable file if missing, including for legacy miners. It reuses a matching existing file instead of creating another wallet on each login. The same file and passphrase work in Veld Wallet and Veld Node.

Keep the file private. Encryption protects the contents, but the keyfile is still a private credential. Never send it to support or another person.

02 / Import

Import the keyfile

Have the exact keyfile passphrase ready and use only https://wallet.veld.network. Decryption and identity validation happen locally in the browser.

  1. Open the official wallet

    Confirm the address bar shows HTTPS and the exact Veld Wallet hostname.

    https://wallet.veld.network

  2. Open Wallet Settings

    Select Log in, or open More → Settings on mobile. A fresh browser shows creation and import choices.

    Wallet navigation: Settings

  3. Select Import keystore file

    Choose the .veld-keys or encrypted miner.key file from the device picker. Files larger than 4 MiB are rejected.

    Log in: Import keystore file

    Seeing Unlock instead? This browser already stores a keystore. Back it up before signing out or replacing it.

  4. Enter the file’s passphrase

    For a wallet file, enter the password and select Unlock. For an encrypted miner.key, enter its passphrase and select Decrypt & Import. Passphrases are case-sensitive.

03 / Verify

Verify the wallet address

After the wallet opens, compare the displayed Veld address with the address you expected before sending, staking, registering, or signing anything.

  • The address begins with V.
  • The first and last characters match your known address.
  • The complete address matches when copied and compared.
  • The keyfile remains backed up separately from its passphrase.
If the address is different, stop. Do not move funds. Lock the wallet and confirm that you selected the correct file.

Troubleshooting

I cannot find a .veld-keys file

Look in the node's data folder for veld-wallet-<first 8 address characters>.veld-keys. If missing, sign in to that encrypted identity using the current client and check Logs. Preserve both files if a conflict or write failure is reported; do not delete or replace the identity to force startup. If the browser wallet is accessible, use Wallet Settings → Save file.

The wallet says “Wrong password or corrupt keystore”

Confirm that the passphrase belongs to this exact file and preserve capitalization and spaces. Use another known-good backup rather than modifying the file.

Does importing move my VELD?

No. Funds remain on-chain at the same address. Importing gives this browser the encrypted signing identity needed to use that address.
