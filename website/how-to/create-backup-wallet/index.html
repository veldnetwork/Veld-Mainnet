How-to / Wallet

Create and back up a Veld wallet

Generate the wallet on your device, protect it with a strong passphrase, and confirm that the encrypted backup can be recovered.

Open Veld WalletAbout 6 minutes
01Generate 02Protect 03Back up 04Verify

01 / Generate

Create the wallet locally

Use a trusted, updated device and open only the official wallet address. The private key and encrypted keystore are created locally in the browser.

  1. Open the official wallet

    Confirm HTTPS and the exact hostname before continuing.

    https://wallet.veld.network

  2. Open Settings

    Select Log in, or open More → Settings on mobile. A browser without an existing keystore offers creation and import choices.

    Wallet navigation: Settings

  3. Select Create New Wallet

    The wallet generates a new private key and derives its Veld address on this device. Record the displayed address so you can verify future imports.

    Log in: Create New Wallet

Your Veld address is public; your private key is not. Never paste the private key into chat, email, cloud notes, or a support request.

02 / Protect

Set the keyfile passphrase

The passphrase encrypts the wallet file. It is not a recovery seed: losing both the keyfile and private key cannot be fixed with the passphrase alone.

  • Use at least 16 characters.
  • Prefer a password-manager value or Generate 128-bit multi-word passphrase.
  • Keep the passphrase separate from every copy of the keyfile.
  • Preserve spaces and capitalization exactly.
Do not photograph the private key. If you choose to retain a raw-key backup, keep it offline and physically separate from the encrypted file. The encrypted .veld-keys file is the normal recovery method.

03 / Back up

Save more than one encrypted copy

  1. Download the keystore

    After entering and confirming the passphrase, select Save & Download Keystore. The file normally downloads as:

    veld-wallet-V1234567.veld-keys

  2. Move one copy off the device

    Keep the original in a protected location and place a second encrypted copy on an external drive or other access-controlled backup.

  3. Store the passphrase separately

    A password manager or a physically separate offline record is appropriate. Do not store a text file containing the passphrase beside the keyfile.

Good separation
Encrypted keyfile on an external drive; passphrase in a password manager.
Weak separation
Keyfile and a passphrase text file in the same folder or cloud account.

04 / Verify

Prove the backup works

A backup is not complete until it has been tested. Use a separate browser profile so the working wallet remains untouched.

  1. Open a separate browser profile

    Go to the official wallet, open Settings, and choose Import keystore file.

  2. Import the backup copy

    Select the copy stored in the backup location—not the original Downloads copy—and unlock it with the saved passphrase.

  3. Compare the complete address

    The derived Veld address must match the address recorded when the wallet was created. Lock or sign out of the verification profile afterward.

If the address differs or the file will not unlock, the backup is not verified. Return to the still-accessible wallet, use Wallet Settings → Save file, and test the fresh copy.

Final checklist

  • At least two encrypted keyfile copies exist.
  • One copy is stored away from the primary device.
  • The passphrase is stored separately.
  • A backup copy successfully opens the expected address.
  • No key or passphrase was shared during the process.

Continue with your wallet

Once your backup is verified, follow Send and receive VELD to fund the wallet. To lock funds for vault distributions, use Stake VELD and understand co-mining, including the minimum balance, lockups, and withdrawal steps.
